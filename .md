# API Testing with pytest and requests (ITDS362)

This repository contains the API test suite for **QuickPizza** (`https://quickpizza.grafana.com`) using Python, `pytest`, and `requests`.

## Student Information
- **Course:** ITDS362 Software Quality Assurance and Testing
- **Lab:** API Testing with pytest and requests

---

## Setup and Execution Instructions

### 1. Environment Setup
Create and activate a Python virtual environment:

**Windows PowerShell:**
```powershell
python -m venv .venv
.\.venv\Scripts\activate
```

**macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run Test Suite
To run all tests and view output in terminal:
```bash
pytest -v
```

To run all tests and generate a self-contained HTML report:
```bash
pytest -v --html report.html --self-contained-html
```

## Input Domain Model (`POST /api/ratings`)

The table below describes the Input Domain Model for `POST /api/ratings` based on **Base Choice Coverage** (Step A1 & Step A2).

| Characteristic | Blocks | Values in the tests | Test covering the block |
| :--- | :--- | :--- | :--- |
| **C1 Value of stars** | below 1 | `0` | `test_stars_out_of_range[0]` |
| | 1 to 5 (base) | `3` | `test_base_choice_is_saved` |
| | above 5 | `6` | `test_stars_out_of_range[6]` |
| **C2 Type of stars** | whole number (base) | `3` | `test_base_choice_is_saved` |
| | decimal | `3.5` | `test_stars_invalid_type[3.5]` |
| | text | `"3"` | `test_stars_invalid_type[3]` |
| | missing | no `stars` field | `test_stars_missing_field` |
| **C3 Pizza** | exists (base) | a new pizza ID | `test_base_choice_is_saved` |
| | does not exist | `999999999` | `test_pizza_does_not_exist` |
| **C4 Token** | user's own (base) | header from `auth` | `test_base_choice_is_saved` |
| | none | no `Authorization` header | `test_rating_no_token` |
| | wrong length / invalid | `"token short"` | `test_rating_invalid_token` |
